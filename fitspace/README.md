# FITSPACE — Public Netlify version 4

Read **START_HERE.md** for deployment and first-time admin/PT setup.

Public browsing needs no password. Customer, PT and admin accounts retain
normal sign-in and role protection. No shared demo accounts are seeded.
Payments are simulated and emails remain previews. PostgreSQL and Node.js 24
are required. Deploy the whole source through Netlify Git import or CLI.
